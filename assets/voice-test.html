Blind Preference Test

Part of the Voice Guide Kit. Everything runs in this page. Nothing you paste is uploaded or stored anywhere.

Two rules make this test work.
  • You are not spotting the AI. Pick the version you would rather have sent. Whether something reads as AI matters far less than whether it is better.
  • Say why, every time. Quote the sentence, say what is wrong with it or what the better one got right, and give the fix if you have one. The score tells you where you stand. The comments are the only thing you can build the next guide out of.
Input format 
[
  {
    "id": 1,
    "label": "Short description of the situation",
    "reader": "Who it is addressed to",
    "mine": "The full text of the piece you actually wrote",
    "draft": "The full text of the AI version, from the brief and the guide"
  }
]

Plain text in "mine" and "draft", with real line breaks. Start a line with "- " for a bullet. This page shuffles which side is A and which is B for every pair, so neither you nor your assistant can leak the answer key.
